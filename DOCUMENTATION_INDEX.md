## Documentation Standards

### Writing Style
- **Clear and concise** - Avoid unnecessary complexity
- **Action-oriented** - Use imperative mood for instructions
- **Consistent terminology** - Use standard terms throughout
- **Examples provided** - Show, don't just tell

### Formatting
- **Markdown** - All documentation in Markdown format
- **Headers** - Hierarchical structure (H1 → H2 → H3)
- **Lists** - Bullet points for items, numbered for sequences
- **Code blocks** - Syntax highlighting for code examples
- **Tables** - For comparisons and structured data

### Maintenance
- **Version control** - Track changes in git
- **Update frequency** - With each release
- **Review process** - Peer review before merging
- **Archive policy** - Keep historical versions
